# Canada Work Permit Portal (Demo)

A responsive front-end demonstration project built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and application form
- `styles.css` — responsive visual design
- `script.js` — demo form handling and local application tracking

## Run locally
Open `index.html` in a web browser. No build tools are required.

## Important limitations
- This is an independent demo, not a Government of Canada or IRCC website.
- It does not determine eligibility, provide immigration advice, issue permits, or submit applications to IRCC.
- Form records are stored only in the browser's `localStorage` on the current device. They are not sent to a server and will not sync across devices.
- Do not enter real passport numbers, identity details, financial information, or upload sensitive documents. This starter project does not implement secure authentication, encrypted storage, file handling, or a backend.
- Check current requirements and apply only through official Government of Canada channels: https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada.html

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, and `script.js` to the root of your repository.
2. In GitHub, open the repository settings and find **Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the published Pages URL to appear.
